# 알바킹 (Mr. Alba King) — 게임 소개

**NAN 2026 사전 과제 출품작 · 웹 브라우저 게임 (설치 불요)**

> 오늘도 알바는 계속된다 — 5~10초짜리 알바 미션 30연속. 김밥 말고, 커피 따르고, 박스 던지고, 탬버린 치며 30라운드 만근에 도전하세요.

## ⏱ 60초 플레이 가이드 (심사위원용)

1. **플레이 링크 클릭** → 로딩 2초 내 타이틀 → **[출근하기]** 탭
2. 1라운드(김밥천국)에서 **가이드 3탭**: 재료 잡기 → 김밥에 놓기 → "주문표 순서대로만!"
3. 주문표의 **번호 순서대로** 재료를 드래그 — 엉뚱한 재료(페이크)를 넣으면 시간이 깎입니다
4. 이후 라운드는 지시어 한 단어가 곧 규칙입니다: **부어!**(꾹 눌렀다 초록 구간에서 놓기) → **올려!**(샤리 위 그림과 같은 재료 매칭) → **날라!**(박스 연타 — 트럭 짐칸으로) …
5. 60초면 미니게임 10종 전부를 한 바퀴 돌 수 있습니다(제출 영상 실측: 59초에 1~10라운드 완주). 목숨 3개 — 실패해도 다음 라운드로 전진하며, 11라운드부터 난이도 티어가 오릅니다.

## 게임 방법

- **목표**: 30라운드 만근. 10라운드마다 난이도 티어 상승(수량↑·시간↓·판정 구간↓) — 21라운드부턴 BGM도 템포업으로 바뀝니다.
- **목숨/점수**: 목숨 3개. 클리어 100점+남은 시간 보너스, 제한시간 40% 이상 남기면 퍼펙트 가산. 연속 성공 콤보.
- **근무 평가서**: 게임오버 시 사장님이 당신의 플레이 기록(테마별 성과)을 보고 잔소리/칭찬을 남깁니다.

### 알바 10종

| 지시어 | 알바 | 조작 |
|---|---|---|
| 넣어! | 김밥천국 | 주문 순서대로 재료 드래그 (페이크 주의) |
| 부어! | 카페 | 꾹 눌러 채우고 초록 구간에서 놓기 |
| 올려! | 초밥집 | 샤리 위 표시와 같은 재료를 매칭 드래그 |
| 날라! | 택배 상하차 | 박스 연타 — 3타마다 위치가 도망감 |
| 찍어! | 편의점 | 주문 수량만큼 스캐너에 드래그 |
| 건져! | 치킨집 | 왕복 게이지가 구간에 올 때 탭 |
| 담아! | 빵집 | 주문 수량만큼 트레이에 드래그 |
| 문질러! | 세차장 | 스와이프로 거품 닦기 |
| 뒤집어! | 붕어빵 노점 | 상승 게이지 타이밍에 탭 |
| 흔들어! | 노래방 | 좌/우 번갈아 연타 (같은 쪽만 치면 효율 급감) |
