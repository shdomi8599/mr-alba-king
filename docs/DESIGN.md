# DESIGN — 게임 설계 (GDD)

> P1 진입 시 본격 작성. 확정분만 기록한다.

## 확정

- 장르: 알바 체험 마이크로게임 연발 (레벨당 5~10초, 즉시 이해 가능한 한 단어 지시어)
- 실패 처리: 목숨제 + 점수제 (실패해도 전진 — 심사자 콘텐츠 노출 극대화)
- 난이도: EWMA 스킬 점수 + 목표 성공률 70~80% 제어기 → 사전 검증된 사다리 풀에서 선택 (ADR-001)
- 템플릿 3종: A 드래그&드롭 / B 타이밍 탭·게이지 / C 연타·스와이프 — 템플릿당 스킨 3~4개
- 코어 규칙: 게임 로직은 렌더와 분리 (순수 TS 모듈 · 고정 타임스텝 · 시드 RNG) — 봇 QA·스튜디오 프리뷰의 전제
- 화면: 세로형 중심 반응형 캔버스, 데스크톱 중앙 정렬, 탭/드래그 공용 조작

## 미정 (P1에서)

- 캔버스 논리 해상도, 템플릿별 상세 스펙, 레벨 JSON 스키마, 텔레메트리 스키마, 미니게임 1차 라인업
