## 발견과 조치

### 1. [버그] 노래방 클리어 불가능 — 전 페르소나 0% (run1)
- 원인: 게이지 감쇠가 클리어 판정보다 먼저 적용 → 만충(1.0) 도달 즉시 다음 틱에 1.0 미만으로 하락, 판정 영원히 불성립.
- 조치: 만충 래치(`gauge < 1`일 때만 감쇠) — `templates/mash.ts`. run2에서 100% 정상화 확인.
- **로직/렌더 분리 덕에 봇이 출시 전 잡아낸 실제 결함.**

### 2. [밸런스] 치킨(사인 게이지) 서열 밖 난이도
- run1: 전문가 d2 0%, run2 완화 후에도 초보 d0 37%·mid d1 23%.
- 조치(2회): 속도 1.7+0.40d → 1.45+0.25d → **1.3+0.22d**, 사인 기본 구간 폭 0.22 → **0.24**.
- run3: 초보 d0 77%, 전문가 d2 90% — 진행 곡선 정상화.

### 3. [밸런스] 타이밍 상위 티어 공통 완화
- 구간 축소율 0.04/티어 → **0.035**, hold·saw 속도 증가율 0.12·0.13 → **0.10**.

### 4. [밸런스] 드래그·연타 계열이 벤치마크(김밥) 대비 과이완
- 조치: match 시간 ×0.93, quantity ×0.95, 택배 목표 12+5d → **14+6d**, 세차 거품 내구 260+50d → **300+60d**.
- 주의: 드래그 계열은 경로 탐색 봇에게 포화(100%) — **봇 절대값은 불신, 상대 서열로만 사용**(전략 원칙).
  사람의 난이도는 인지 부하(판별·판단)에서 나오므로 드래그 추가 조임은 실플레이 검증 후 판단.
